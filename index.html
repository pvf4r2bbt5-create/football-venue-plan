运行目标

  • 安全：隐患可识别、风险有控制、应急能响应。
  • 有序：观众、运动队、裁判、媒体及救援流线尽可能分离。
  • 准时：场地交付、入场、比赛衔接和场地转换按竞赛日程执行。
  • 服务：提供清晰导向、饮水、卫生、咨询及无障碍协助。
  • 闭环：问题有记录、责任人、整改期限和复核结论。

管理边界

  • 场馆运行负责人统筹场馆空间、服务、设施和现场运行资源。
  • 竞赛规则、赛程、裁判判罚及比赛是否继续，由竞赛组织体系按规程决定。
  • 公安、消防、医疗、交通等专业事项由具备职责和资质的部门实施。
  • 遇即时生命安全危险，现场人员先采取必要避险、报警和救助措施，同时报告指挥中心。
人数口径：1000人/天是每日累计观众量，不等于同时在场人数。必须以售检票/计数数据、场馆核定安全容量和分区承载能力控制实时人数。

场馆运行指挥中心（VOC）

态势监控 · 通信调度 · 信息汇总 · 事件记录 · 指令传达 · 资源协调

竞赛与场地组

竞赛联络、场地交接、器材、检录、更衣室、训练热身衔接。

安保与人流组

外围秩序、入口、安检协同、看台、重点区域、散场和疏散。

设施工程组

供配电、照明、广播、网络、监控、显示系统、工程抢修。

医疗卫生组

赛场急救、观众医疗、救护车接应、医疗转运和卫生巡检。

观众服务组

咨询、票证引导、座席指引、无障碍服务、失物和投诉。

后勤交通组

餐饮饮水、物资仓储、停车落客、车辆调度、保洁垃圾。

媒体信息组

媒体签到、授权区域、信息发布、摄影采访与新闻服务。

志愿者与机动组

岗前培训、排班考勤、岗位补位、流动支援、休息轮换。

外部联动单位

公安、消防、属地医疗、交警、体育主管部门及场馆管理方。

指挥原则：专项组对本专业工作负责；区域负责人对区域状态负责；重大风险及时上报VOC；现场指令要复诵确认并反馈执行结果。
04 / 场馆功能分区

“八区一中心”功能规划

① 比赛核心区

足球场、技术区、替补席、场边医疗通道。严格证件准入。

② 竞赛保障区

运动队更衣室、裁判室、检录区、会议及工作间。

③ 运动员服务区

热身、饮水、休息、恢复及球队候场区域。

④ 观众服务区

观众入口、安检验票、看台、卫生间、咨询点。

⑤ 媒体工作区

媒体签到、采访、混合采访区及授权拍摄位置。

⑥ 医疗救援区

观众医疗点、赛场医疗点、救护车停靠与转运通道。

⑦ 后勤保障区

物资仓库、餐饮饮水、保洁、垃圾暂存和设备间。

⑧ 运行指挥区

VOC、监控、通信调度、运行日志和应急资料。

分区原则：以实际建筑平面、消防设计、场馆许可及运营条件为准。不得为实现“分区”而封堵法定疏散路径；临时隔离设施必须经场馆和安全管理负责人确认。

08 / 赛前筹备

赛前30天倒排计划

T-30 至 T-21
组织启动与现场踏勘：明确主承办责任和联系人；核查场馆平面、核定容量、出入口、停车、消防、医疗、供电、广播、监控；形成问题清单和责任分工。
T-20 至 T-15
方案编制与资源锁定：完成场馆运行方案、安全工作方案、风险评估、医疗保障、交通组织、信息发布、熔断与应急预案；确认人员和外部保障资源。
T-14 至 T-8
场馆布置及系统测试：设置分区标识、引导标识、隔离设施；检查球门器材、草坪、照明、广播、通信、监控、应急照明及备用供电。
T-7 至 T-4
全员培训与岗位实操：开展岗位职责、证件权限、观众服务、对讲机、医疗呼叫、消防避险、恶劣天气及异常事件报告培训。
T-3 至 T-2
联合演练：模拟观众入场高峰、运动员检录、赛场伤病、看台突发情况、火情疏散、停电、暴雨雷电和散场。
T-1
终检、验收与封场：逐项销项；确认岗位、物资、通信、外部联络；召开赛前联席会；由有权责任主体完成开放条件确认。
若实际筹备周期不足30天，应按风险和关键路径压缩，但不得压缩依法必须履行的审批、验收、培训、演练和专业检查环节。

11 / 三天差异化管理

首日磨合、次日稳定、末日收官

第1天｜开赛日

  • 重点检查首次执行流程。
  • 观察观众到场峰值及排队时长。
  • 核验检录、更衣、热身、场地交接顺畅度。
  • 问题现场登记，明确次日调整责任人。

第2天｜稳定运行日

  • 按首日数据优化入口开岗和岗位布点。
  • 检查设施连续运行、保洁和物资库存。
  • 落实人员轮休，防止疲劳值守。
  • 复核天气变化和赛事风险。

第3天｜收官日

  • 提前准备决赛/关键比赛安保和观众组织。
  • 若有颁奖，设置仪式区、嘉宾流线和器材。
  • 提前部署散场交通与失物处理。
  • 比赛结束后转入撤场和正式交接。
每日复盘必须形成“问题—原因—措施—责任人—完成时限—复核结果”清单。第二天、第三天的运行方案根据实际情况动态修订。
12 / 观众入场

每日1000名观众的入场与容量管理

外围到达 / 落客停车
→
入口分流排队
→
安检及禁限带物品检查
→
验票 / 人数计数
→
看台分区引导

进场组织

  • 明确观众入口、开放时间、分区和票证方式。
  • 设置排队缓冲区，队列不得占用消防、救护或交通通道。
  • 入口采用实时计数；异常拥堵时按预案暂停放行、分流或调整入口。
  • 达到批准容量或分区控制阈值时停止放行，按指挥程序处置。

看台管理

  • 按看台分区安排引导与巡查人员。
  • 保持横向、纵向通道及出口无障碍。
  • 禁止观众擅自进入比赛、媒体、更衣和技术区域。
  • 为老年人、儿童及行动不便观众提供合理协助。
1000名/天不能直接用于推算安检通道数或疏散时间。需要观众到场分布、入口有效通行能力、场馆安全容量、安检流程和当地安全评估数据后，才能计算峰值排队与人员布点。
13 / 观众服务与散场

看台运行、异常处置和分区离场

引导服务

入口导向、座席指引、卫生间与饮水点指示、无障碍通道和服务台。

秩序维护

通道巡查、违规闯入、冲突纠纷、物品遗失、走失人员报告。

散场组织

按看台区域分流，确保出口及外部道路承载衔接，不形成逆向人流。

散场执行顺序

确认比赛/仪式结束
→
发布离场提示
→
分区引导放行
→
外围交通接续
→
区域清场复核
如出现局部拥堵，优先控制新增人流进入拥堵区域，安排人员疏导并为医疗救援留出通道；不得采用相互冲突的广播和现场口令。

运动员服务

  • 按参赛队分配更衣室和储物区域，落实钥匙/权限管理。
  • 提供饮水、卫生间、休息及必要的恢复空间。
  • 热身区与观众区、比赛区合理隔离。
  • 运动员伤病立即联系医疗组，避免非授权人员围观。
  • 赛后按队伍安排离场，保持通道清晰。

裁判与技术官员

  • 独立签到、休息、更衣及赛前会议安排。
  • 核查工作证、比赛资料、通信设备和工作席位。
  • 控制裁判工作区域准入，防止无关人员干扰。
  • 提供饮水、工作餐、轮休和必要的工作支持。
  • 竞赛问题按竞赛规程向裁判长/竞赛负责人报告。

19 / 应急指挥

事件上报、调度与闭环“五步法”

01

发现

第一发现人报告准确位置、事件类型、涉及人数、现场风险。

02

报告

立即向VOC报告；重大安全、火灾、伤病事件同时按要求报警/呼救。

03

响应

值班长通知相关专项组，按预案启动资源调度和现场控制。

04

处置

专业部门实施救援和处置；场馆团队负责通道、秩序、信息和资源支持。

05

恢复

确认安全条件、获授权后恢复运行；形成记录并开展复盘整改。

指挥纪律

赛事暂停/恢复由竞赛规程和赛事应急机制授权主体决定；场馆团队负责风险报告和执行。生命安全受到即时威胁时先采取必要保护措施。

无线电标准：呼叫对象 → 报告位置 → 说明事件 → 说明已采取措施 → 提出资源请求 → 复诵确认 → 反馈处置结果。
20 / 天气与交通

气象监测、外围交通及车辆保障

天气监测

  • 赛前和赛中持续关注官方气象预报、预警。
  • 雷电、暴雨、大风、高温分别明确监测责任人和信息通报渠道。
  • 检查临时广告、遮阳棚、围挡等设施的稳定与防风措施。
  • 高温安排饮水、遮阴、休息和医疗关注。
  • 积水及时排查，危险区域隔离并报告。

交通与停车

  • 运动队/竞赛官员车辆与观众车辆尽可能分流。
  • 设置车辆落客区、停车区域和步行引导路径。
  • 救护车、消防通道优先，任何车辆不得占用。
  • 与交警和交通部门保持联络，提前部署散场交通。
  • 车辆凭证、临停时间和调度联系人明确。
